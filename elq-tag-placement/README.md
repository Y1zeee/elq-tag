# ELQ Tag Placement

Static page for placing new SITA tags (XS + 8 digits) on ELQ-2 devices.

- `index.html` – the page (needs `assets/style.css`, Google Fonts and ExcelJS from cdnjs).
- Host with GitHub Pages: Settings > Pages > deploy from branch, root.
- Saved tags are stored in each person's own browser (localStorage). They are not shared between users, so each person downloads their own Excel and the files are merged afterwards.
- Excel/CSV export downloads straight from the browser.
